Most organizations don't know what they can't see. Lamont is a shadow asset inventory tool that surfaces the credentials, integrations, and identities that exist outside official inventory — and maps each finding to the questions that matter: who created it, what can it reach, and does it still need to exist.

Three Shadow Categories
Shadow IT
Unmanaged Infrastructure
Systems, services, and cloud resources that exist outside official inventory. Exposed directories, forgotten dev servers, misconfigured endpoints, rogue cloud deployments.
Shadow AI
Unauthorized AI Integration
AI tools and LLM integrations authorized by individual users without IT visibility. OAuth grants to ChatGPT, Notion AI, Grammarly, Copilot — each one a data pipeline nobody approved.
Shadow Identity
Orphaned Credentials & NHI
Service accounts, API keys, OAuth tokens, and machine credentials operating without current ownership. The attacker doesn't break in — they inherit keys that were already there.

About

Lamont is an independent tool developed by Charlie Niemi (CISSP, MSIA, MBA). The shadow asset taxonomy, five-question archaeology model, and three-category framework are original contributions. Implementation is AI-assisted.

Lamont uses TruffleHog, Nuclei, and Amass as signal sources, normalizing findings into a common schema organized around the five archaeology questions. Each finding is mapped to a shadow category, a confidence tier, and a remediation posture.
